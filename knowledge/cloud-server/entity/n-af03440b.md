# 浏览器用户

## 定义

通过浏览器访问 `https://memhub.work` 查看/操作记忆面板的最终使用者。

## 关键属性

- 入口：443 → [[nginx]] → `127.0.0.1:8125`（[[tdai-memory-hub]] 面板）。
- 受 nginx 限流约束：`/api/v1/auth/` 6 次/分（burst 4），其余 30 次/秒（burst 60）。
- 受安全响应头保护（nosniff / SAMEORIGIN / no-referrer）。

## 关系

- 与 [[管理员账号]]（主机权限）、[[Claude Code 与 Agent 客户端]]（注入链路）区分。
- 是 [[单入口反向代理架构]] 面向公众的唯一边界。
