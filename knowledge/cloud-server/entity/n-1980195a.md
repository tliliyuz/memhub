> 百度智能云侧常驻在服务器 A 上的主机安全/管理 agent 集合（bcm-agent、checkmce、bsm-agent、has-agent），占用公网端口 781 与 428，运维上不可停止、不可修改。

# 定义

[[百度智能云]] 在 [[服务器 A（instance-47g8z54m）]] 内部署的一组主机安全与管理 agent，
与业务进程（[[ClickHouse]]）共置同一宿主，是主机上**不由运维者掌控**的第二类负载。

# 关键属性

- **硬约束**：不要重启、停止或改动这四类进程。它们是云厂侧的管理通道，
  改动可能触发主机被判定异常或失去云侧纳管。
- **黑盒**：端口 781 / 428 是 A 机上除 SSH 之外唯一的公网监听面，但对外行为不可由本侧审计。
- **推断来源**：这四个进程同时也是判断「A 机属百度智能云」的依据。
