# 管理员账号

## 定义

管理员账号指对两台主机执行运维操作的唯一人类身份（旧页中称“本人”）。两台主机的登录方式与身份落点**不同**，必须明确区分，避免混淆：

| 主机 | 登录主体 | 来源 | 认证方式 |
|---|---|---|---|
| [[腾讯云 CVM VM-0-10-ubuntu]]（B 机） | 运维者（近 7 天唯一 SSH 成功记录） | `180.173.121.131` | 密钥；密码登录状态见下文“冲突与待核实”（旧页称已禁密码，新页称仍开启、待收紧） |
| [[服务器 A（instance-47g8z54m）]]（A 机） | `root@120.48.25.220` | 未在原文记录 | 密钥（`PermitRootLogin without-password`，`PasswordAuthentication no`） |

## 关键属性

### B 机（[[腾讯云 CVM VM-0-10-ubuntu]]）

- 来源 IP：`180.173.121.131`，为近 7 天**唯一**成功 SSH 登录来源。
- 已在 [[fail2ban]] 白名单中，同时受 [[腾讯云安全组]] 放行，因此不会被误封。
- SSH 使用密钥登录。旧页记载 root 登录策略为 `PermitRootLogin without-password`（禁密码、允许密钥）；新页则称密码登录仍开启、待收紧，详见冲突说明。
- 持有 `/opt/memhub` 下敏感文件：`.env`、`.admin-key`（权限 `600`）。

### A 机（[[服务器 A（instance-47g8z54m）]]）

- root 账号（`root@120.48.25.220`）只能以密钥登录；密码认证整体关闭（`PasswordAuthentication no`），`MaxAuthTries 6`。
- SSH 开放 **22 与 2222 双端口**。
- 所有内部访问（[[ClickHouse]] 隧道、内网）都以该 root 身份发起；即**无独立业务账号**，运维与数据访问合一，属可改进项。

## 冲突与待核实

- **B 机密码认证状态**：旧页称 root 登录策略为 `PermitRootLogin without-password`（禁密码、允许密钥），即 SSH 使用密钥；新页称 B 机密码登录仍开启、待收紧。两处记载矛盾，均予保留，待以最新配置核实。
- 旧页另记载，管理员是待办“确认密钥可用后关闭密码认证”的决策者。
