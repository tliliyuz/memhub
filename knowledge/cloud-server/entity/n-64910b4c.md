> 服务器 A 的云厂商（依据 bcm-agent / checkmce / bsm-agent / has-agent 推断），提供主机并托管其安全与管理 agent。

# 定义

百度智能云是 [[服务器 A（instance-47g8z54m）]] 的云厂商，提供该台 2 vCPU / 1886 MiB / 40 GiB 的
云服务器（公网 120.48.25.220，内网 192.168.16.2），并在主机内常驻一组主机安全/管理 agent。

原文并未直接读出 cloud provider 标识，而是**依据进程推断**：

| 证据进程 | 说明 |
|---|---|
| `bcm-agent` | 监听 0.0.0.0:781（公网可达） |
| `checkmce` | 监听 0.0.0.0:428（公网可达） |
| `bsm-agent` | 运行中，无独立监听 |
| `has-agent` | 运行中，无独立监听 |

# 关键属性

- 与 [[腾讯云 CVM VM-0-10-ubuntu]]（B 机，腾讯云）构成**跨云双机**格局，见 [[双机角色分工]]。
- 云侧边界（安全组等）在 A 机上**未在本快照中核实**：A 机 ufw 未启用、iptables 默认 ACCEPT，
  实际入站过滤依赖云侧策略 + [[fail2ban]]。与 B 机已确认的 [[腾讯云安全组]] 形成对照。
- 其 agent 具有「不可停止、不可修改」的运维约束，见 [[云厂商托管组件约束]] 与
  [[百度智能云主机安全与管理组件]]。
