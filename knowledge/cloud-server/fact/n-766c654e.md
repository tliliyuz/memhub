> 以 nginx 作为唯一公网收口，内部服务全部隐藏；任何新增公网能力都必须经过反代与鉴权。

# 单入口反向代理架构

## 定义

系统只对外暴露**一个** HTTP(S) 入口（[[nginx]] 的 443，80 仅做 301 跳转），所有业务能力以回环端口形式挂在它后面，由它统一完成 TLS 终止、路由、限流、安全头与访问控制。

## 意义

- 安全边界收敛到一处：审计、限流、鉴权、日志只需在一个组件上做（见 [[主机安全防护分层]] 的应用层）。
- 与 [[最小暴露面绑定原则]] 配合，形成"绑定层不可达 + 代理层受控可达"的双重保障。
- 新增公网能力有唯一标准路径：**子域名 + 反代 + 鉴权**，而不是直接放通端口。

## 拓扑角色

- 外部用户：[[浏览器用户]] → [[nginx]]:443 → `127.0.0.1:8125`（[[tdai-memory-hub]]）→ [[tdai-memory-core]]。
- 待落地：[[tdai-proxy]] 的 8096 未来若需公网，也应走此模式（见待办 4）。
