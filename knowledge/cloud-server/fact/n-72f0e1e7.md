> memhub 记忆栈的标准操作序列：启动/重建、停止、健康检查、fail2ban 状态、nginx 校验重载、证书续期验证。

# 运维操作手册

## 定义

针对 [[腾讯云 CVM VM-0-10-ubuntu]] 上 memhub 记忆栈的日常操作与校验流程集合。

## 关键路径

| 路径 | 用途 |
|---|---|
| `/opt/memhub` | 三件套启动脚本、`.env`、`.admin-key`（均 600） |
| `/etc/nginx/sites-available/memhub` | 公网入口配置 |
| `/etc/nginx/proxy_params_memhub` | 反代公共参数 |
| `/etc/fail2ban/jail.local` | fail2ban 策略 |
| `/root/.config/magpie/settings.json` | magpie 配置（含 `lanKey`） |

## systemd 单元

`memhub-stack.service`（oneshot，core → hub → proxy）、`magpie-gateway.service`、`nginx.service`、`docker.service`、`fail2ban.service`。

## 常用命令

```bash
systemctl start memhub-stack          # 启动/重建三件套
/opt/memhub/stop-all.sh               # 停止三件套
/opt/memhub/verify.sh                 # 健康检查
fail2ban-client status sshd           # 查看封禁情况
nginx -t && systemctl reload nginx    # 校验并重载 nginx
certbot renew --dry-run               # 验证证书续期
```

## 注意事项

- 修改任何容器参数（如内存 limit）必须改 `/opt/memhub` 脚本，重启后生效（[[容器化部署与重建语义]]）。
- 改 nginx 配置后先 `nginx -t` 再 reload，避免入口中断（[[单入口反向代理架构]]）。
- 涉及数据卷的操作前先手工快照（[[Docker 卷数据持久化]]）。
- 操作者身份见 [[管理员账号]]。
