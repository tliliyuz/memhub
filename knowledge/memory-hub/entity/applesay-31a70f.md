> 团队命名空间，作为记忆归属与客户端初始化表单中的一级选择项。

# 定义

`applesay` 是记忆归属的第一级命名空间（团队层级），在客户端初始化表单与记忆导入中作为一级选择项出现。

# 关键属性

- 归属层级：团队（第一级）→ 项目（第二级）
- 本环境下的项目：[[SDP Tag 项目]]（归属 `sdp-tag-doc`）
- 出现位置：[[DSH Desktop]] 初始化表单、[[Codex 会话导入工具]] 的关联选择

# 关系

- 与 [[项目记忆归属与 Agent 分配]]：两级归属模型的上层
- 与 [[Memory Agent]]：Agent 按团队/项目分配
- 与 [[applesay 上游模型服务]]：同名命名空间，但属不同系统（注意区分）
