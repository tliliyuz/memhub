> 只积累仓库里没有的隐性知识（术语、决策背景、排障经验、已验证方法），设计/开发文档仍以源码仓库为准。

# 定义

记忆系统只沉淀**源码仓库里没有的隐性知识**，其余仍以仓库为准，避免文档双写与漂移。

# 沉淀边界

| 进入记忆 | 留在源码仓库 |
| --- | --- |
| 业务术语 | 项目设计文档 |
| 决策背景（为什么这么做） | 开发文档 |
| 排障经验 | 代码与 API 契约 |
| 被验证过的工作方法 / 操作流程（→ [[Skill]]） | — |

# 意义

- 记忆的价值在于"仓库里查不到"的上下文，而非复制文档。
- 明确边界可防止 Wiki/Chat Memory 与代码仓库出现事实不一致。
- 与 [[三类资产模型]] 互补：策略说"沉淀什么"，资产模型说"沉淀到哪、怎么更新"。
