# 桌面登录门禁

## Definition

桌面登录门禁是 `crates/desktop/src/App.tsx` 中的进入判定逻辑，用于决定应用启动后是否渲染 LoginView（登录页）。它是 [[界面门槛与鉴权分离]] 这一概念的直接实现证据。

```
if (!env.config_exists || env.profiles.length === 0 || prefill) → LoginView
```

## Key Attributes

- **kind**: module
- 判定表达式三项条件任一成立即进登录页：配置文件不存在、profiles 为空、或 `prefill` 被置位。
- 门禁只决定**能否进入主视图**，不承担鉴权：真正的校验发生在用户点「连接」时（见 [[凭据边界]]）。
- 「直接进来了」不等于跳过登录，而是本机早已登录过：`config.toml` 有 profile、凭据库有对应 key，界面判定「已配置」。

## 机制：prefill 预填登录

- 触发条件：**有 profile 但 `has_user_key === false`**（由 [[桌面登录入参]] 暴露）。
- 行为：登录页以**预填**方式打开，只补 key，不重建 profile。
- 依赖：`env.profiles.length` 与凭据状态彼此独立——profile 存在不代表 key 存在，这正是 prefill 分支存在的理由（见 [[多 profile 隔离]]）。

## Relationships

- 判定条件依赖 [[配置文件 config.toml]]（`env.config_exists`）与 [[profile]]（`env.profiles`）。
- `prefill` 由 [[桌面登录入参]] 的 `has_user_key` 驱动：后端状态 → 前端分支。
- 实现并体现 [[界面门槛与鉴权分离]]。
- 凭据缺失时的后果由 [[系统凭据库]] 与 [[凭据边界]] 定义。
