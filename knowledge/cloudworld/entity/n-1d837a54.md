# 凭据模块

## Definition

凭据模块是 `crates/core/src/credentials.rs`，负责集中定义凭据库的访问常量与 account 命名规则，并实现写入密钥的子命令 `credential set`。它是 [[系统凭据库]] 的唯一读写方。

## Key Attributes

- **kind**: module
- 常量：`KEYRING_SERVICE = "cloud-world"`、`USER_KEY_SUFFIX = "panel-user-key"`、`RELAY_TOKEN_SUFFIX = "relay-token"`。
- account 命名规则：`<profile>:<suffix>`，前缀来自 [[profile]]，构成 [[多 profile 隔离]]。
- `credential set` 的输入方式：
  - 隐藏输入（交互式），或 `--stdin` 从标准输入读取；
  - **拒绝命令行位置参数**（`--key xxx` 一律不接受）；
  - 输出**不回显**密钥内容。
- 这些约束是 [[密钥不落盘原则]] 在 CLI 侧的落点：命令行在 Windows 上对其他用户可见，等于把密钥写进系统日志。

## Relationships

- 读写 [[系统凭据库]]，常量与 account 命名规则在此对齐。
- 实现 [[密钥不落盘原则]] 的输入侧约束（隐藏输入 / `--stdin` / 拒绝位置参数 / 不回显）。
- 与 [[桌面登录入参]] 共处同一条 [[key 生命周期数据流]] 的两端（写入 vs 使用），共同维持内存不扩散。
- 与 [[配置文件 config.toml]] 明确分工：模块只处理敏感项，配置文件不承载任何密钥。
