> 由 cloud-world.exe 以 --config-dir … relay --profile default 拉起的独立后台进程，监听 8787，生命周期与窗口解耦。

# 定义

relay 后台进程由 [[cloud-world.exe]] 通过 `--config-dir … relay --profile default` 拉起自身而成，是独立于窗口的后台服务，负责维持模型连接。

# 关键属性

| 属性 | 说明 |
| --- | --- |
| 启动方式 | `cloud-world.exe --config-dir <dir> relay --profile default` |
| 监听端口 | 8787 |
| 配置来源 | 运行期读取 [[运行期配置文件 config.toml]] 中的 `profile`、端口等 |
| 生命周期 | 与 GUI 窗口解耦：关窗口不断连 |
| 断开方式 | 界面点「断开」或 `cloud-world disconnect` |
| 生产实例二进制 | `target\debug\cloud-world.exe`（被 [[watchdog 计划任务]] 持有文件锁） |

# 关系

- 生产实例由 [[watchdog 计划任务]] 拉起并长期维持。
- 与界面拉起的 relay 争同一 8787 端口，构成 [[relay 单实例与端口互斥]] 约束。
- 其占用的 `target\debug\cloud-world.exe` 是 [[构建目录隔离]] 的直接动因。
