> 会话请求中携带的 team/agent/task 指定（x-team-id/x-agent-id/x-task-id），属资产解析链第二档，被第一档命中时整体忽略。

# 定义

请求头预设指调用方在会话请求中通过 `x-team-id` / `x-agent-id` / `x-task-id` 指定的 team / agent / task，是 [[资产解析优先级链]] 的**第二档**输入。

# 关键属性

| 请求头 | 语义 |
| --- | --- |
| `x-team-id` | 指定 team |
| `x-agent-id` | 指定 agent |
| `x-task-id` | 指定 task |

# 关系

- 仅当 [[账号级默认会话资产记录]] 不存在时才会被 [[会话初始化服务]] 采用。
- 与第一档是**短路关系**：账号默认存在时，三个请求头被整体忽略——这是「指定 `x-agent-id` 无效」的原因，属预期行为（[[预期行为 vs bug 判定]]）。
- 优先于第三档 [[交互式资产选择表单]]。

# 常见误区

请求头不生效不等于请求头被丢弃或串号，而是优先级更高的账号默认已给出确定取值。
