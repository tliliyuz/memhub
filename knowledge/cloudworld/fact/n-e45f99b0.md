> 前端热更新 + Rust 自动重编重启窗口，打包成本只落在发版、不落在开发。

# 定义

开发态不打包，使用 Tauri 的 dev 模式：

```powershell
cd crates\desktop
npm run tauri dev
```

前端改动热更新，Rust 改动自动重编并重启窗口。

# Significance

- 把 [[打包分层模型]] 中的 exe 重编成本限制在发版环节：「每次改都要打包」这个成本只落在发版，不落在开发。
- 缩短反馈周期，避免为了看界面效果而反复打包。
- 注意：debug 构建有可见副作用（多一个控制台窗口），外发前必须换 release，见 [[cloud-world.exe]]。

# 约束

- dev 模式的构建输出默认落在 `target\`；若生产 relay 占用该路径，需改用 `--target-dir target-build`，见 [[构建目录隔离]]。
