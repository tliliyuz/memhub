# 08-验收证据分层

## 文档摘要

本文是 [[cloud-world 桌面端]] 在 2026-11-12 的一次验收证据报告。核心主张：交付报告里「做完了」不构成证据，**没做什么**才是；把「未做项」单列成表比只报通过项更有用。该主张沉淀为概念 [[验收证据分层]]。

报告由四部分组成：

1. **实测口径**（[[实测口径]]）：构建、测试、前端、真实请求、诊断、资产的当次实测结果。
2. **单列出来的未做项**：4 条缺口原样保留，其中「clippy 不可用」被特别强调——缺 lint 时报告「构建无警告」容易被误读为「代码质量已检查」。
3. **隔离测试做法**（[[隔离测试]]）：一次性 profile、凭据不落盘、断开顺序、构建输出改道。
4. **数字要以实测为准**：README 曾写「74 个测试」，实测为 73。

## 实测结果（原文数据）

| 项 | 结果 |
| --- | --- |
| `cargo build` | 无警告 |
| `cargo test --workspace` | 73 passed, 0 failed（core 29 · api 14 · relay 5 + 集成 16 · service 5 · cli 2 · desktop 2） |
| 前端 | `tsc --noEmit` + `vite build` 通过（242 kB JS / 75 kB gzip） |
| 真实请求 | 经 [[本地 relay]] → 云端 proxy → magpie：HTTP 200 / 1685 ms / `"pong"` |
| 诊断（隔离 profile） | `ok 13 / warn 5 / fail 0`，WARN 全为「未连接 + dev_resolve」预期项 |
| 诊断（生产） | `ok 16 / warn 2 / fail 0` |
| 资产 | 85 条可见，默认资产与 CLI 一致 |

## 未做项（原样保留）

1. 只跑了 `--no-bundle --debug`，**没有产出 NSIS 安装包**；`tauri.conf.json` 里的 nsis 目标与图标未走正式打包流程。
2. **只在 Windows 实测**；`DETACHED_PROCESS` 是 Windows API，macOS/Linux 等价路径未验证。
3. 界面不提供 `--config-dir` / `--claude-dir` 入口，隔离测试靠环境变量。
4. `clippy` 本机不可用（`cargo-clippy.exe` 缺失），只做了 `cargo build` + `cargo test`，**没有 lint 结论**。
