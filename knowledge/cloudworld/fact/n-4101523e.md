# 真实请求链路

## 定义

cloud-world 用以证明端到端连通性的数据流路径：**[[本地 relay]] → 云端 proxy → magpie**。

## 链路节点

| 节点 | 角色 | 说明 |
| --- | --- | --- |
| [[本地 relay]] | service（链路起点） | 本地进程，接收请求并转发；验收后需确认状态与 bridge 端口 |
| 云端 proxy | service（转发层） | 把本地 relay 的请求转发给上游 magpie；本文件信息较少，未单独建页 |
| magpie | external_system（链路终点） | 上游服务，返回 `"pong"` 作为连通性证据 |

## 证据

2026-11-12 的实测结果为 **HTTP 200 / 1685 ms / `"pong"`**，数值须符合 [[实测口径]]。

## 意义

- 是 [[验收证据分层]] 中唯一的真实网络证据，区别于构建/测试这类本地证据。
- 通常在 [[隔离测试]] 的一次性 profile 下执行，避免污染生产配置；其诊断结果为该链路提供旁证（隔离 `13/5/0`、生产 `16/2/0`）。
