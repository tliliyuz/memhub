> 默认资产写入的成员关系、agent 归属与可见性校验全部在服务端完成，客户端不做本地猜测，失败时原样透传服务端错误。

# 定义

服务端权威校验原则指：涉及 [[账号级默认会话资产记录]] 写入（`user-session-default/set`）的权限判断——成员关系、agent 归属、可见性——**全部由服务端**（[[资产服务]]，`crates/service/src/assets.rs`）完成，客户端不复制、不推断这些规则。

# 校验项

| 校验项 | 说明 | 归属 |
| --- | --- | --- |
| 成员关系 | 调用者是否属于目标 team | 服务端 |
| agent 归属 | agent 是否归属于该 team / 账号 | 服务端 |
| 可见性 | 资产对调用者是否可见 | 服务端 |

# 重要性

- 避免客户端与服务端规则漂移导致的「前端以为合法、服务端拒绝」类问题。
- 明确失败处理方式：**不要在前端猜原因**，将服务端错误原样透传给用户。
- 与 [[资产解析优先级链]] 形成完整闭环：读取侧由优先级决定取值，写入侧由服务端决定是否允许。
