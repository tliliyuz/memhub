> 记录「改哪一层需要重新打包」的结论、exe/安装包/配置三层发布物模型、拒绝远端热更前端的理由，以及用 target-build 做构建隔离的做法。

# 文档摘要

本文回答「改哪一层需要重新打包」这一问题，并给出可执行的发布物分层与构建隔离做法。

核心结论：**改界面、改 Rust、改 service 逻辑都必须重新编译**，因为前端产物在编译期被 `generate_context!()` 嵌进 exe；**改 profile、端口、面板地址、`user_key` 都不用重编**。把这两类混在一起，会得出「每次改都要打包」这个错误成本预期。参见 [[打包分层模型]]、[[编译期前端嵌入]]、[[运行期配置与凭据分离]]。

# 分层表

| 改动内容 | 要不要重打包 | 原因 |
| --- | --- | --- |
| `.tsx` / `.css` / Rust 命令层 / service 逻辑 | **要** | 前端在编译期嵌入（`frontendDist: "../dist"`），不从磁盘读；改一行 CSS 也要重编 |
| profile、端口、面板地址、`dev_resolve` | 不用 | 运行期从 `%APPDATA%\cloud-world\config.toml` 读 |
| `user_key` | 不用 | 系统凭据库 + 界面重新登录 |

# 三个容易混的层次

1. **exe** —— 代码改动都要重编。首次 release 要把全部依赖过一遍（几分钟）；之后只重编 desktop crate + 前端（几十秒到两分钟）。对应实体 [[cloud-world.exe]]、构建单元 [[desktop crate]]。
2. **NSIS 安装包** —— 只是把 exe 包一层。exe 变了安装包就得重出；已装机器要么重跑安装包，要么直接覆盖 exe。发安装包记得升 `tauri.conf.json` 的 `version`，否则新旧版本号一样，升级与卸载记录会混。对应实体 [[NSIS 安装包]]。
3. **配置** —— 不进二进制，改完重启应用即可。对应实体 [[运行期配置文件 config.toml]]、[[系统凭据库]]。

# 日常迭代根本不打包

```powershell
cd crates\desktop
npm run tauri dev
```

前端热更新、Rust 改动自动重编并重启窗口。**「每次改都要打包」这个成本只落在发版，不落在开发。** 详见 [[开发态迭代]]。

# 为什么不把前端放服务器热更

理论上可以让窗口加载远端 URL，改界面不用重编 exe。但这与两点直接冲突：当前 CSP 是 `default-src 'self'`；以及产品定位要求「不依赖网络也能用」（域名备案问题已经证明网络不可依赖）。这是安全性和可用性的双重倒退，不采用。详见 [[离线优先与 CSP 约束]]。

# 构建目录隔离：别覆盖正在运行的 exe

背景：`target\debug\cloud-world.exe` 被 watchdog 计划任务长期占用（生产 relay 从它启动），直接 `cargo build` 会因文件锁失败或替换掉生产二进制。

做法：构建输出到独立的 `target-build\`，用 `--target-dir`：

- 好处：不碰被占用的 `target\debug\`，生产 relay 不受影响。
- 代价：产物在 `target-build\debug\`，**不是正式产物位置**，需要人工记住路径。
- `.gitignore` 需同时包含 `target-build/`（否则隔离目录反而污染仓库）。

详见 [[构建目录隔离]]、[[watchdog 计划任务]]、[[relay 后台进程]]。

# debug 构建的可见副作用

`main.rs` 里 `windows_subsystem = "windows"` 只在非 debug 时生效，所以 debug 版双击后会多一个黑色控制台窗口，关主窗口时它跟着走。这不是缺陷，但发给别人前要换成 release。已并入 [[cloud-world.exe]] 的关键属性。

# 关窗口不会断连

relay 是独立后台进程（`--config-dir … relay --profile default` 拉起自己）。关窗口不断模型连接；要断得在界面点「断开」或 `cloud-world disconnect`。

**同时只能有一套 relay**：watchdog 维持的生产 relay 与界面拉起的 relay 抢同一个 8787 端口。界面检测到端口已有 relay 就不再拉起（正确）；但若从界面点「断开」，会把生产 relay 一起停掉。详见 [[relay 单实例与端口互斥]]。
