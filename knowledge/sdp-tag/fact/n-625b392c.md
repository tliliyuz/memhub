> 打标第一级且是硬门禁；当前 7 个、无「家居」；2026-10-27 只改展示层名称为「行业」。

# 场景

## 定义（实义）

打标的第一级，对应代码 `scene`。当前 7 个：服装、鞋履、箱包、配饰、美妆护肤、香氛、宠物。

场景不是「模型判出来的软分类」，而是**硬门禁**：一个场景都没命中，整单 `blocked`（日志「上游场景无命中，未执行」），**标签阶段根本不跑**。

## 重要性与影响

- [[标签]] 阶段的「0 标签」很多时候根本不是标签阶段的问题，而是上游场景未命中 `[D]`。
- 空输出归因 `scene_miss` 属于 [[状态与归因语义]] 的一部分。
- [[打标阶段模型]] 的第一段就是场景。

## 改名历史（2026-10-27，提交 `288d0b3`）

前端展示层统一「场景」→「行业」（含 `sys_menu.menu_name`），**但只改展示层** `[Z]`：

| 保留「场景」的地方（不要误改） | 说明 |
| --- | --- |
| `scene` / `sceneId` / `sceneName` / `sceneDefinition` | 代码标识符 |
| `graph:scene:*` / `tag.lab.scene` / `LabStageCode.scene` | 权限码与枚举 |
| 后端 Prompt 文本、图谱表/字段注释 | — |
| 图谱定义正文（「本场景」「归家居场景」） | [[图谱团队]] 维护 |

## 易误解

- **没有「家居」scene**。RL 100 件里有 20 件家居商品，**没有 coverage 分母** `[Z]`——这不是缺陷，是 [[知识图谱]] 的范围。
- 首页「多租户场景」是通用语义，不是本体系的三级结构术语 `[Z]`。

## 验证方式

- 查 `graph_scene` 表记录数（7 条）。
- 查 blocked 任务日志中的「上游场景无命中，未执行」。
