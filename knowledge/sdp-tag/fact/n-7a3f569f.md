# 数据库变更管理

## Definition

sdp-tag 的数据库 schema 变更如何执行、由谁负责、如何留痕。

## Significance

**系统没有任何自动迁移机制**，这意味着「发布代码」与「变更数据库」是**两个必须手工对齐的动作**，错序就会炸。

## 关键事实

- **POM 里没有 Flyway / Liquibase**，应用不扫描 `script/sql/`
- Maven 构建资源只有 `src/main/resources`，该目录**不在其内**
- **打包、部署、重启都不会执行 SQL**

## 执行顺序

新列必须先 apply `script/sql/update/*.sql`，否则报 `Unknown column`（`content_digest`、`origin_url_hash` 都踩过）。

## 命名规范

`日期_两位序号_变更名称.sql`

## 禁令与约束

- ⚠️ **不要批量遍历整个目录执行**——混有正向、回滚、历史框架升级、不同方言脚本
- ⚠️ **没有「每个脚本只执行一次」的系统保证**，靠人工台账：`路径 + SHA-256 + 版本 + 执行人 + 时间 + 结果`
