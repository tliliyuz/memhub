> 提示词只保留通用判断协议，标签语义下沉到图谱的备注与维度定义——修图谱关系而不是加条款。

# 定义

提示词只承载**通用判断协议**（什么算、什么不算、修饰词不作依据），标签级别的语义（儿童/婴童、棉/棉质/纯棉、多面料）应放进**标签备注**与**维度定义**。遇到判断错误时，**修图谱关系而不是往提示词加条款**。

# 版本演进表

最终定版（2026-10-20）：`scene v3 + dim v3 + label v7`（lab 显式 ID；published 指针仍是 v1/v1/v1）。

| 版本 | 内容 | 结果 |
| --- | --- | --- |
| label **v1** | 166+180 字符，短通用协议，含标签备注 | 干净，最终回落点 |
| label **v2** | — | 内容损坏（实际是场景阶段 prompt），不可用 |
| label **v3** | 473+245 字符，长规则手册（4 通用规则 + 3 判定口径），1063 token/题 | 婴童错误上升；tokens +62.6%，判失败 |
| label **v4** | 117+228 字符，加标签专属条款（0%/少量、KID） | 修好婴童但打破儿童，96 个香调同义词爆炸 |
| label **v5 / v5.1** | 加儿童/材质条款 / 压缩到 257 字符 | 儿童恢复，但人造棉升到 0.73，暴露错误关系 |
| label **v7** | v4 的短系统提示 + v1 的用户提示 | **最终定版**，tokens −8.2%，行为等价 |

# 意义（根因洞察）

> **4,692 个标签的 `remark` 100% 为空。** 标签语义无处安放 → 提示词被迫累积全局规则 → 全局规则有跨标签副作用。

长规则手册的失败模式是典型的：修一类（婴童）必然打破另一类（儿童）。只要语义还压在提示词里，就会持续付这个税。

# 代价

- 备注填充是**图谱团队的工作**；填完之前只能靠 v5.1 这类临时桥接。
- 短期看起来「提示词工程不努力」，实际瓶颈在数据资产。
