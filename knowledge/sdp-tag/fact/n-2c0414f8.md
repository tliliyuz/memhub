> 2026-11-05 落地的按维度设置 label 阈值的功能，只做机制不写默认值。

# 定义

分维阈值机制是「阈值可按维度（dimension）分别配置」的能力，2026-11-05 落地。

**关键约束：只做机制，不写默认值。** 即代码/配置支持分维覆盖，但系统不内置任何维度的默认阈值。

# Significance

- 是 [[阈值分层]] 的下一层延伸：从「按宿主分层（lab 0.7 / pipeline 0.9 / doubao 0.999）」到「按维度细分」。
- 「不写默认值」意味着线上行为仍由 [[正式打标链路]] 的全局阈值 `tag.pipeline.label-threshold`（0.9）决定，除非显式配置。
- 不改变 [[补全路径]] 的免阈值特性。
