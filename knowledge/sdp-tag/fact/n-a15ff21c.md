> 商品打标项目 2026-10-19~11-06 的演进时间线汇总与三批来源材料（C/D/Z）冲突时的五项仲裁规则，是整套知识库的导航与仲裁层。

# 概述

本文件是一份**元文档**而非某个子系统的一手设计文档：它汇总商品打标（labeling）项目约两个月（2026-10-19 ~ 11-06）的演进时间线，并给出三批来源材料（C / D / Z）冲突时的裁决规则。

核心主张：**这个项目多次改向，同一条结论在不同时间点可能正好相反，因此引用任何结论前必须先确认口径与版本。**

因此本页在知识库中承担 [[仲裁口径]]、[[三批材料的权威分工]]、[[引用标注规范]] 三层职责，是后续所有页面引用的前置条件。

# 仲裁口径（三批冲突时怎么判）

见主页面 [[仲裁口径]]，规则摘要：

1. **代码 > docs Spec > 会话/记忆**
2. **时间近的 > 时间远的**，但按事件类型区分（架构决策取最新；一次测量结果取当时的；失败教训永久有效；环境问题只在当时环境有效）
3. **批次冲突先判断是否为「同一件事的不同阶段」**（如三阶段 → 两阶段）
4. **数字冲突先查分母与口径**（strict/inference、unknown 是否入分母、直标 vs 含补全）
5. **无法裁决则两条都写并标注冲突**，收入 [[未决与空白登记]]

# 四个高频错误

见 [[评测口径陷阱]]：混比不同 rubric、把砍标签抬高的准确率当改善、忽略 [[补全路径]]、把实验台阈值当线上阈值（见 [[阈值分层]]）。

# 三批材料分工

见 [[三批材料的权威分工]]：没有任何一批能单独支撑全部主题，必须合并而非选一批。

# 引用格式

见 [[引用标注规范]]：任何数字必须带「数字 + 样本 + 模型/口径 + 日期」四要素。
