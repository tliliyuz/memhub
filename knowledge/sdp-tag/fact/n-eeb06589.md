> 由 (id>>12)&31 的 worker 位与 config_hash 判断是否有另一份旧配置进程在写同一库；NAT 出口 IP 不是外部实例。

# Definition

用雪花 ID 的位段反推「写入方是谁」，从而判断同一个库是否有**另一份进程**在写。

```
worker = (id >> 12) & 31
dc     = (id >> 17) & 31
```

# Significance

- 症状是「任务莫名失败 / 数据被改」。实例：任务是 `worker 16/15`、`4/15`，当前 Pod 是 `14/19`；`config_hash` 是 `1b5bb6…`，当前 Pod 是 `0b544f…` → **另一份旧配置的进程**。
- 它把「有人在同时写库」从猜测变成取证，是[[排障范式]]里「最小区间 + 唯一假设」的落地手法。

# 误判警告

`49.235.144.47` 是**本 pod 的 NAT 出口**，不要当成外部实例。
