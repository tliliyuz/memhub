> 按严重度分级的凭据风险清单与处置动作；核心原则是「改回 ${} 引用不等于消除泄露，必须真轮换」。

# 凭据泄露与轮换

## Definition

对系统中已泄露/易泄露凭据的**分级登记 + 处置动作**机制。核心原则：

> ⚠️ **改回 `${}` 引用 ≠ 消除泄露**——旧值已在 git 历史里，**必须真的轮换**。

## Significance

sdp-tag 的凭据问题不是零散失误，而是**结构性**：多处凭据明文落库/落 git 历史且已实质泄露，其中最高危是「一处口令攻破三处系统」。

## 风险清单（按严重度）

| 级别 | 项 | 为什么严重 |
| --- | --- | --- |
| 🔴 极高 | RDS root + ACR 口令**同值**（`sx@12345…`） | 一处泄露 = 镜像仓库 + dev 库 + 生产库 → [[aliyun-rds-instances]]、[[acr-registry]] |
| 🔴 极高 | 对方 `cfg_api_key` 被 root 直读 | 对方大概率不知情；prod ZARA key 有真实线上写权限 → [[partner-brand-tenant]] |
| 🟠 高 | `sk_5dIyx…` 明文进 git | 长期凭据（365 天）、http、无白名单无限流 → [[api-key-authorization]] |
| 🟠 高 | 7 把 LLM key 明文在会话/yml | 直接消耗额度 → [[llm-gateway-applesay]] |
| 🟠 高 | kubeconfig 在 `Downloads` | **cluster-admin 级**（`auth can-i '*' '*'` = yes）→ [[ops-subaccount-cluster-admin]] |
| 🟡 中 | `admin/admin123` + 固定 client-id | superadmin 弱口令 → [[lab-admin-account]] |
| 🟡 中 | 老服务 `source.zara.token` | admin-api 会话凭证，已随 zip 外流 |
| 🟢 低 | SnailJob 内网地址 `192.168.31.20:17888` | 仅内网，但暴露拓扑 → [[snail-job]] |

## 处置动作模板

1. **换值**（dev / prod 分开，不同用途不再同值）
2. **yml 改成 `${ENV_VAR}` 引用**（默认值留空）
3. **同步更新 K8s Secret** → [[k8s-secret-injection]]
4. **`rollout restart`**（环境变量只在启动时读取）
5. 评测 key 优先用专用环境变量（`LAB_ACCURACY_API_KEY`），不要用 yml 默认值

## 绝不能进仓库的清单（§9）

| 类型 | 具体 | 正确做法 |
| --- | --- | --- |
| DB 口令 | `application-dev.yml:58` / `application-prod.yml:62` | `${SPRING_DATASOURCE_DYNAMIC_DATASOURCE_MASTER_PASSWORD}` + Secret |
| Redis 口令 | `application-dev.yml:112` | `${SPRING_DATA_REDIS_PASSWORD}` |
| SnailJob token | `${SNAIL_JOB_TOKEN}` | ✅ 已经是引用 |
| 回调 key | 任何 yaml 里的 `CALLBACK_AUTH_VALUE` | Secret `sdp-tag-callback` |
| LLM key | `application.yml` 的 `api-key` 默认值 | `${LLM_CHAT_API_KEY}` / `${LLM_JUDGE_API_KEY}`，**默认值留空** |
| 对外 API Key | `docs/Spec/2026-10-28-图谱接口示例.md:34` | 占位符 + 申请流程 |
| kubeconfig | `Downloads/cls-*-config` | 移到 `~/.kube/` 或凭据管理器 |
| 对方凭据 | 对方 zip 里的 `application-prod.yml` root | 不复制进仓库 |
| 本机覆盖配置 | `config/application-private.yml` | ✅ 已 Git 忽略 |
| 评测原始数据 | `.local/lab-accuracy/` | ✅ 已忽略 |
| lab 批次导出 | `lab-batch-*.json`（单批 10 件约 9.7 MB） | 浏览器导出，不进仓库 |
