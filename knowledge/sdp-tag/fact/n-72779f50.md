> lab-accuracy-v2（strict）与 lab-accuracy-v3-inference 分母定义不同，2026-10-27 起官方默认改为 inference，历史数字全部是 strict，两者不可同列比较。

# 定义

判分口径（rubric）决定准确率的分母如何构造——特别是 unknown / 未判定项是否计入分母。项目内存在两个口径：

| rubric | 名称 | 说明 |
| --- | --- | --- |
| `lab-accuracy-v2` | strict | 历史默认；Zara 79 baseline 与 RL 各版数字均为该口径 |
| `lab-accuracy-v3-inference` | inference | 2026-10-27 起成为官方默认 |

# 关键事实

- 同一批数据下 strict 68.2%、inference 88.0%（`[Z]`）——**混在一列里就是错的**。
- 2026-10-27 判分口径改为 inference 默认。
- 历史数字（Zara 79 baseline、RL 各版）**全部是 strict**。

# Significance

- 是 [[评测口径陷阱]] 错 1 的定义来源。
- 是 [[仲裁口径]] 规则 4 的范式案例：`87.4%` vs `84.9%` 的差异本质是「RL 100 混合场景」vs「Zara 79 四场景」，连同 rubric 一起构成不可比。
- 与 [[官方评测标准]] 分层：rubric 定义「怎么打分」，官方标准定义「谁来打分、分歧怎么办」。

# 引用要求

按 [[引用标注规范]]，任何准确率必须写成：

```
准确率 85.2%（79 件，qwen3.8-flash，lab-accuracy-v2 strict 口径，2026-10-22）[Z]
```
