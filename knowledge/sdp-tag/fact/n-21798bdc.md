> 分维阈值存 graph_dimension.label_threshold，使实验台/正式链路/异步任务自动一致，代价是调一个阈值即全量缓存失效。

# 定义

分维阈值不放在配置文件或独立配置中心，而是存进 [[标签图谱]] 的 `graph_dimension.label_threshold` 字段。

# 意义（为什么挂表）

图谱快照本来就随 [[TagTaskRunSpec]] 走，挂表就能让**实验台、正式链路、异步任务自动一致**，不需要额外的配置发布流程。

# 代价（必须知道）

- 阈值进了 `configHash` → **调一个维度阈值 = 全量缓存失效**。
- 阈值**不进** `graphHash` → 改阈值不会翻转图谱指纹（这反而方便区分「改定义」和「改阈值」）。

# 三个看似无关但必然的配套技术决定

| 决定 | 不加会怎样 |
| --- | --- |
| 字段用 `Double` 不用 `BigDecimal` | `JacksonConfig` 把 `BigDecimal` 全局注册成 `ToStringSerializer`，`configHash` 的 JSON 里出现字符串 `"0.900"`，前端 `el-input-number` 出错 |
| 必须 `@JsonInclude(NON_NULL)` | 新字段以 `"labelThreshold":null` 进序列化 → **升级部署那一刻所有商品的配置指纹都变 = 全量重打** |
| `updateStrategy=ALWAYS` | 把值改回之前的值时不写库 |
