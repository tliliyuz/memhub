> Spring Boot 五层配置来源及优先级，关键反直觉点：config/application-private.yml 优先级低于 application.yml，写进去永不生效。

# 配置分层与优先级

## Definition

Spring Boot 配置来源按优先级**从低到高**排列：

```
application.yml（含 Maven 占位符）
  └─ application-{profile}.yml
       └─ config/application-private.yml   ← spring.config.import 导入
            └─ 环境变量
                 └─ 命令行 -D / --xxx
```

## Significance

这是所有配置问题的根，理解错就会「改了配置却没生效」并且**完全没有报错**。

### 三个反直觉的点

1. **`config/application-private.yml` 优先级低于 `application.yml`**——「把 key 写进 `application-private.yml` **永远不生效**」（真实踩过）
2. **`spring.config.import: optional:file:./config/application-private.yml`** 里的 `optional:` 意味着文件不存在也**静默跳过**
3. **环境变量名是「点换下划线、去掉连字符」**，见 [[env-var-relaxed-binding]]

## 配置文件位置

| 环境 | 路径 |
| --- | --- |
| 本地/仓库 | `sdp-tag-backend/sdptag-admin/src/main/resources/application{,-dev,-prod}.yml` |
| 运行目录覆盖 | `<cwd>/config/application-private.yml`（**Git 忽略**） |
| 容器内 | `/sdptag/server/config/application-private.yml`（从 Secret 只读挂载） |
