> 评测侧 judge 的三条独立评审路径（first/second/tiebreak）及仲裁；与 official 的 J1/J2/J3 分层。既有记录另有将三评描述为 J1/J2/J3 多判模型的口径，两说并存待核。

# 三评架构

## 两种口径（冲突并存，待核）

现有资料对「三评」的所指存在冲突，本页保留两种说法并明确标注：

- **口径 A（新页补充）**：三评指 judge 阶段的**三条独立评审路径**——`first` / `second` / `tiebreak`，三者是并行的判定角色，各自独立判定后交仲裁环节裁决。新页明确反对把三评等同于 J1/J2/J3 级联。
- **口径 B（既有页记录）**：三评曾被记录为 **J1/J2/J3 多判模型架构**，即 J1 全判、J2 只判第一轮 unknown、J3 只判翻转；official 后改为 J1/J2 并发 2-of-3。

两种口径不是同义关系：新页认为「三评 = 三级联」是典型口误型误解；既有页则把 J1/J2/J3 级联记在「三评架构」条目下。以下分别保留事实。

## 口径 A：三条独立评审路径（新页补充）

### 字面意思 vs 团队实义

- **字面意思**：三次评测，看起来像对同一样本跑三遍。
- **团队实际含义**：judge 阶段的**三条独立评审路径** —— `first` / `second` / `tiebreak`。三者是**并行的判定角色**，各自独立判定后交仲裁环节裁决。
- **易混淆点**：新人常以为是把同一个样本评测三次取平均。实际是三个**不同角色**各自判定，再由仲裁流程定结论。

### 澄清要点

| 误解 | 实义 |
|---|---|
| 三评 = 跑三遍 | 三评 = 三条不同角色的评审路径 |
| 三评 = 重复抽样取平均 | 三评 = first / second 各自判定 → 分歧时 tiebreak 仲裁 |
| 三评 = 模型自身稳定性检验 | 三评 = 判定流程的分工，不是对同一角色的采样 |

三条路径判定的是 judge 的三值输出（support / contradict / unknown），见 [[judge-三值判定]]、[[judge 三值判定]]。

### 验证方法

- 看评测输出里是否出现 first / second / tiebreak 三组独立判定记录，而不是同一路径的三次重复。
- 看仲裁记录是否只在 first/second 分歧时触发 tiebreak——若是「每次都跑三遍」，则说明实现被改坏了。

## 口径 B：J1/J2/J3 多判模型（既有页记录）

评测侧的多判模型架构。**按此口径，三评不是「三个 judge 全判」**——这是最容易被误解的架构点 `[Z]`。

| 阶段 | 谁 | 范围（qwen 组） |
| --- | --- | --- |
| 1 | `qwen3.8-flash` | 全部输出对（5,707） |
| 2 | `gpt-6.1-sol` | **只判第一轮 unknown**（1,081） |
| 3 | `grok-4.7` | **只判第二轮翻转**（461） |

漏斗：15,678 全量 → 2,827 unknown → 1,240 翻转 → 384 接受。

### 架构盲点

按该 J1/J2/J3 级联口径，约 **12,851 对在第一轮就判了 support/contradict 的，后面任何 judge 都不会复查** `[Z]`。

## official 流程层（与三评的关系存在分歧）

[[官方评测标准]] 属于 official 流程层。官方口径（2026-10-27 起）：

- official 子命令 = **J1 与 J2 并发全判，J3 只判分歧，2-of-3**。每对至少两个意见，分歧有三个。
- 新页补充：official 流程层曾/在代码侧是级联 J1→J2→J3（J1 全判 / J2 只判第一轮 unknown / J3 只判翻转），后改为 J1/J2 并发 2-of-3。

新页强调：这一层应称 official 的 J1/J2/J3，不应与「三评」混为一谈。一句话区分（新页口径）：**三评是「谁在判」，official 的 J1/J2/J3 是「按什么顺序判、判哪些」**。把「三评」说成「三级联」是典型的口误型误解。

## 为什么不是过度设计 `[D]`

标签判定的两轮一致率只有 **67.5%**，比维度门（96.4%）低得多。

## 自评偏差 `[Z]`

生成标签的是 [[qwen3.8-flash]]，它同时也是第一判模型。三评是**缓解**，不是消除。

## 易误解

- 以为三评覆盖了全部样本：按既有 J1/J2/J3 级联口径，第一轮已定性的 12,851 对无复查。
- 把 unknown 当作「判错」：它在三评里是**弃权票**，不进分母，见 [[judge 三值判定]]、[[门控]]。
- 把三评说成「跑三遍」「重复抽样取平均」「模型自身稳定性检验」：新页明确这是误解；三评是角色分工，不是对同一样本重复采样。
- 把三评说成「三级联」：新页称为典型口误型误解；既有页曾在此条目下记录 J1/J2/J3 级联，二者冲突已在上文标注。
