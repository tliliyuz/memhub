> dev/prod 在 profile、vhost（前导斜杠）、库名、Redis db（6/3）、回调 URL 上的成对差异；队列名相同，环境无法靠队列名判断。

# 环境隔离

## Definition

dev / test 与 prod 两套环境在各配置维度上的成对差异清单。

## Significance

隔离手段**不成体系**：有的靠 profile、有的靠前导斜杠、有的靠实例、有的靠端口——**没有单一可靠的环境标识**，容易误操作。

## 成对差异表

| 维度 | test / dev | prod | 风险 |
| --- | --- | --- | --- |
| Spring profile | `dev` | `prod` | 主开关 |
| RabbitMQ vhost | `/applesay` | `applesay` | ⚠️ **只差一个前导斜杠，两个完全隔离的 vhost** |
| RabbitMQ 队列名 | `ai_tagging_product` | **同名** | ⚠️ **不能靠队列名判断环境** |
| `AUTO_TAGGING_RABBIT_TENANT_ID` | 无 | `838124` | ⚠️ 不配会烧 5,700+ 条消息 |
| 数据库 | `/sdp_tag_dev` | `/sdp-tag-prod` | 同实例，见 [[aliyun-rds-instances]] |
| Redis db | `6` | `3` | 同实例不同库 |
| 回调 URL | `http://yxzhtest3.applesay.cn/...` | `http://search3.moechat.cn/...` | 见 [[callback-and-brand-allowlist]] |
| MQ 并发 | 1 | 2（曾被调到 10 出事） | 只管消费线程 |
