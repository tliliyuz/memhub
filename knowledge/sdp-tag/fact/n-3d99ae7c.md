> 用 q1..q971 替换 18 位 ID，输入 −23.8% / 输出 −40.4% / 正文 −71%，是唯一未被推翻的优化。

# 定义

把请求里的题号从 `label_<18位>_<18位>_<18位>` 改为短别名 `q1..q971`。

# 收益

| 指标 | 变化 |
| --- | --- |
| 输入 token | **−23.8%** |
| 输出 token | **−40.4%** |
| 合计 | **−31%** |
| 每题正文 | 76 → 22 token（**−71%**） |
| 语义 | **无任何改变** |

题号回显平均 62 字符，是纯冗余成本。

# 意义

> 「这是比门控划算得多的方向。」

在 [[模型门控 vs 服务端阈值筛选]] 决定「接受更多输出 token」之后，短题号成为对冲成本的手段。

# 代价

几乎没有——**这是唯一一个没有被推翻的优化**。

⚠️ 实现细节：状态键**至少带阶段**，避免 `scene:q1` 与 `label:q1` 冲突。
