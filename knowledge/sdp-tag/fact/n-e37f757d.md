> 维度定义必须是原则式描述 + 合成 few-shot，禁止父子互斥/同档互斥等排他条款。

# 定义

维度定义只写**描述性规则**（什么算、什么不算、修饰词不作依据），配**合成的**反例；样本数字只作依据，不进定义。

# 意义

- **排他条款会与图谱既有取值打架**：图谱里父子、近义取值**本来就并存**，写「父子互斥 / 同档互斥 / 只打最细层级 / 近义只取一个」会被 judge 按字面执行，反噬准确率——这是品类 −31pp 的根因。
- **用样本倒推规则不可泛化**：把 100 件的错法翻译成排除条款，换个品牌就失效，还会把 prompt 撑成案例集。
- **真正有用的是描述性规则**：材质、开合方式这类规则实测 +3.4pp / +9.4pp。

# 用户原话

> 「我可以允许有 few-shot 这种做法，但是不要拿这 100 个样本为例，穷举倒退模型的输出，这样没有意义。」

# 禁止的写法

「父子互斥 / 同档互斥 / 只打最细层级 / 近义只取一个」。
