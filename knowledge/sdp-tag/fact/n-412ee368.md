> 任何数字都必须带「数字 + 样本 + 模型/口径 + 日期」四要素，缺一项都会在后续被误用。

# 定义

团队对「如何在文档或回答中标注一个测量数字」的约定：**四个要素缺一不可**——数字 + 样本 + 模型/口径 + 日期。

# Schema

```
<指标> <数值>（<样本量/样本集>，<模型>，<rubric/口径>，<日期>）[<来源批次>]
```

# Examples

**正确**：

```
准确率 85.2%（79 件，qwen3.8-flash，lab-accuracy-v2 strict 口径，2026-10-22）[Z]
```

**不正确（缺口径与日期）**：「准确率 85.2%」——后续无法判断是 strict 还是 inference、是否含补全，必然被误用。

# Significance

- 直接对抗 [[评测口径陷阱]] 中的错 1（混比 rubric）与错 4（实验台阈值当线上阈值）：只要口径被写进引用，混比就很难发生。
- 与 [[仲裁口径]] 规则 4 一致：数字冲突时先查分母与口径，而口径只有在引用中被记录才可查。
- 与 [[判分口径]]、[[阈值分层]] 强耦合：这两处的口径差异最容易被遗漏。

# 需要标注的典型场景

| 指标 | 必须附带 |
| --- | --- |
| 准确率 | rubric 名（[[判分口径]]）、是否含补全（[[补全路径]]）、样本集 |
| 阈值 | 宿主系统（lab / pipeline / 历史方案，见 [[阈值分层]]） |
| 耗时/token | 单件 or 整批、含不含图片下载、commit（见 [[性能与成本基线]]） |
