> gate = min(全局阈值, 所有生效分维阈值)，取最小是单向安全的，但闸门是永久地板，必须再低 0.05~0.1。

# 定义

`gateFloor = min(配置闸门, 本阶段阈值, 该批涉及维度的生效阈值)`，即不变式：

```
gate = min(全局阈值, 所有生效的分维阈值)
```

该不变式要写进运行记录。

# 意义

**取最小是单向安全的**——报告多了只是多花 token，报告少了是**静默丢标签**。宁可多写，不可漏写。

# 代价

闸门是**永久地板**：一旦 `gate=0.7`，任何维度想试 `0.65` 都必须重新打标。因此闸门必须比正式阈值**再低一档**（经验值 0.05~0.1）。
