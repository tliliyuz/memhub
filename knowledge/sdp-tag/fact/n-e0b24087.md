> 两批可比必须同场景对照；A/B 须分直标/补全/并集三层 Jaccard；图谱漂移必须显式对齐，仲裁率高说明判分本身不可靠。

# Definition

让两次/两批评测结论**真的可比**的一组约束，覆盖样本构成、指标层次、判分可靠性与外部依赖版本。

# Significance

没有一致性约束时，数字会「自己变好」：

| 陷阱 | 后果 |
| --- | --- |
| 考题构成差异 | `87.4% > 84.9%` 是场景构成不同，同四场景比反而低 1.4pp，**还在噪声内** |
| 只报并集 | 直标塌缩但并集仍 0.95 → **必须分直标 / 补全 / 并集三层 Jaccard** |
| 仲裁率高 | `设计师合作IP` 仲裁率 **63.2%** → 判分本身不可靠，先修判分不要改打标 |
| 图谱漂移 | 6,352→7,440 标签，新增 1,088 个在旧分母里不存在 |
| 脏判据字段 | `passedDims` 恒空 → 39 个漏打全记成 `dimension_miss`；coverage 用 `>=` 而链路用 `>` |
| 样本静默减少 | 缺 `taggingPrompts` 的旧导出被整件跳过 |
| 预算估算错 | 召回成本是准确率的 **40 倍**（要判全部 1,400 个候选） |
