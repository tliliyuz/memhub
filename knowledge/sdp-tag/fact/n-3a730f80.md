> jev_noul_v1 于 2026-10-21 成为唯一请求协议，删除请求格式选择器，并发布 scene v4 / dim v4 / label v8；79 件评测 85.2% vs 83.0%、tokens −39%。

# 定义

四段结构协议（标识 `jev_noul_v1`）是打标请求的统一结构。2026-10-21 起成为**唯一协议**，请求格式选择器被删除。

# 关键事实

| 项 | 内容 |
| --- | --- |
| 生效日期 | 2026-10-21 |
| 配套版本 | 同时发布 scene v4 / dim v4 / label v8 |
| 评测结果 | 79 件：85.2% vs 83.0%，tokens −39%（2026-10-22） |
| 拆批策略 | 10-22 取消组内 16 题拆批 → 一个语义组一个请求 |
| 边界问题 | 10-26 超限语义组自动拆分，根因是 label v11 太长 |

# Significance

- 是 [[阶段演进]] 中「阶段划分」之外的「请求结构」主线：阶段从三变二，协议保持唯一。
- 与 [[提示词与配置版本演进]] 强耦合：协议变更引发 scene/dim/label 的版本跳变。
- 按 [[引用标注规范]]，85.2% 必须带「79 件 + qwen3.8-flash + lab-accuracy-v2 strict + 2026-10-22」引用。
