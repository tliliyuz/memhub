> 判分口径是评估的第一杠杆：strict 68.2% ↔ inference 88.0%（19.8pp），远大于任何模型间差异。

# Definition

rubric 判分口径指的是 **judge 在什么标准下把一个标签判为「对」**。两种主要口径：

- **strict**：严格匹配，不容忍推断。
- **inference**：**允许合理推断**——模型从证据推出、但未逐字复述的标签也算对。

# Significance（第一杠杆）

同一批 **5,707 标签**：**strict 68.2% ↔ inference 88.0%，差 19.8 pp**。

而这个项目**所有模型间差异都小于它**（同 0.7 阈值）：

| 模型 | 准确率 |
| --- | --- |
| doubao | 65.2% |
| qwen3.8-flash | 75.7% |
| JEV | 85.6% |

> **所以：准确率动了，先问口径变没变。**

# 关键规则

| 规则 | 内容 |
| --- | --- |
| 准确率分母 | 恒为「**已产出的标签对**」——砍标签会抬准确率 |
| inference 的含义 | **允许合理推断**，不是某个公式 |
| 准确率的算法 | 始终 `support / 全部标签` |
| 维度阈值 | 是**替换**（有维度值就用维度值），不是双过滤 |

# 已失效结论

- **B1**：「只判 `response.isOk()` 就够」——2026-10-30 修复后必须 **2xx 且 body.code ∈ {0,200}**。
- **B2**：「维度阈值是双过滤（全局 + 维度都要过）」——**一直都是错的**，实际是替换关系。
- **B3**：「`support/(support+contradict)` 就是 inference 口径」——**一直错**；那是另一个量，inference 指允许合理推断。

# 未决与缺口

- **C11 空标签的计算口径**：「空输出」不是失败，但归因为 `scene_miss` 还是不计入分母，**各处表述不一致**。
- **C12 / E10 阈值 0.8/0.8/0.7 的推导依据**：仓库里没有记录，Spec 只列为「最终决定」，并提到一份**不在仓库里的 JEV 试验报告**。见 [[jev]]。
- **C7 / D7 人工金标准**：所有准确率都是 judge 估计，见 [[无人工金标准]]。
