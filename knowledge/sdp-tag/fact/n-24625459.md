> strict（unknown 入分母）/ 剔除 unknown / inference / 覆盖率 / 漏标·每件正确标签——多个数不可混用、不可挑高汇报。

# 准确率口径

## 定义（实义）

同一批数据可产出多个「准确率」，口径不同：

| 口径 | 定义 |
| --- | --- |
| strict | `support / 全部输出标签`，**unknown 计入分母** |
| 剔除 unknown | 从分母中去掉 `unknown` |
| inference | **允许 judge 合理推断**（面料→厚薄、尺码→年龄、品牌→风格，要求写出推断链）——**不是**剔除 unknown |
| 覆盖率 | 「该打未打」的绝对召回 |
| 漏标 / 每件正确标签 | 召回代理指标 |

同一批数据会出现 `87.4%`（strict）和 `96.0%`（剔除 unknown）两个数，**不要混用、不要拿高的那个汇报**。

## 重要更正 `[Z]`

把 `support/(support+contradict)` 叫作 inference 是**错的**；inference 是允许推断，见 [[judge 三值判定]]。

## 易误解

- **准确率 ≠ 覆盖率**：87.4% 回答不了漏标 `[D]`。
- 漏标与 strict 可以反向：合批实验里「strict 反而高 4~6pp，但漏标导致每件正确标签 −5%~−15%」。
- 分母混入 [[直标与补全|补全]]标签，90% ≠ 模型判了 90%。

## 验证方式

- 报告任何准确率时同时声明：口径、分母构成（直标/补全）、unknown 处理方式。
