> <0.80 可通过抬阈值救回，≥0.90 高分错不可救；距阈值 0.08 以内不算稳定结论。

# Definition

模型判分分数带与人工判定准确率之间的映射关系，用来判断「错误能否通过抬阈值救回」。

| 分数带 | 准确率 `[Z]` |
| --- | --- |
| [0.70, 0.75) | 79.0% |
| [0.75, 0.80) | 80.9% |
| [0.80, 0.90) | 91.9% |
| [0.90, 1.00] | 98.4% |

# Significance

- **`< 0.80` 可救**：抬阈值能把这些样本砍掉。
- **`≥ 0.90` 高分错不可救**：厚薄 0.90 档只剩 82%、尺码 0.95 档 67%、设计师IP 0.99 档 **33%** → 需要改模型/提示词，而不是调阈值。
- **稳定性下限**：分数距阈值 **0.08 以内不算稳定结论**（Zara 香氛批 run-to-run 最大差 0.08）。
- 与 [[闸门阈值]] 的交界：闸门是「配错导致不产出」，分数带是「配对了也不够准」。
