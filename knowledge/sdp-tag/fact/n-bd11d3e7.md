# Definition

未发现项清单是知识库的**完整性契约**：它列举 `[C]` `[D]` `[Z]` 三批材料中**都没有找到**的内容。

> **规则：不要补，不要编。** 需要的话得问人或查代码，不能从本知识库推。

# Significance

- 防止「合理推断」被写成事实，是 [[时间线仲裁口径]] 的补集：仲裁处理「有说法但冲突」，本清单处理「根本没有说法」。
- 每条缺口都指向一个**具体的验证动作**（查代码 / 查 DB / 问当事人），可直接转成任务。
