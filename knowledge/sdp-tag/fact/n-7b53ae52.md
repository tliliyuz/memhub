> 最终标签 = 直标命中 ∪ 图谱补全；补全没有分数、任何阈值管不到，准确率天然低 4~5pp，错误率必须分直标/补全统计。

# 定义

最终标签由两条路径合并而成：

```
最终标签 = 直标命中 ∪ 图谱补全
```

「补全」指通过 [[标签图谱]] 推导补充的标签，**不经过模型打分**。

# 关键属性

| 属性 | 值 |
| --- | --- |
| 是否受阈值约束 | 否——**没有分数，任何阈值管不到**（见 [[阈值分层]]） |
| 准确率相对直标 | 天然低 4~5pp `[D]` |
| 实测准确率 | 36.4% vs 直标 93% `[Z]` |
| 对错误的贡献 | 17.8% 的错误来自补全 `[Z]` |

# 常见误读

- 「支持数 / 最终标签数」达到 90% **不等于**模型判了 90%，因为分母里混入了补全标签。
- 把直标与补全混算错误率，会得出偏差结论（曾发生）。

# Significance

- 是 [[评测口径陷阱]] 错 3 的直接对象。
- 决定了准确率口径必须显式声明「是否含补全」，这也是 [[引用标注规范]] 的要求之一。
- 与 [[判分口径]]（strict / inference）叠加，构成准确率不可比的第二个维度。
