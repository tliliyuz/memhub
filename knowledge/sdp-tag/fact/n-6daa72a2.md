> 每条决策固定写「选了什么 / 放弃了什么 / 为什么 / 代价是什么」，代价栏最易被漏且往往是真正成本所在。

# 定义

本文档自身的元规范。每条决策必须四栏齐备：

1. **选了什么**
2. **放弃了什么**
3. **为什么**
4. **代价是什么**

# 意义

> 「代价那栏最容易被漏掉——很多方案的真正成本不在实现，而在后续维护和回归。」

具体体现：

- 定义补齐的成本是维护与回归，不是 token；
- 分维阈值的成本是「调一个阈值 = 全量缓存失效」；
- 闸门取 min 的成本是「永久地板」。
