> 通过消息队列消费商品变更并触发打标的链路，10-29 集群内打通（26 次模型调用 → 18 个标签），11-03 幂等改为规范化内容摘要。

# 定义

MQ 消费链路是生产化的触发入口：消费商品变更消息，调用打标链路产出标签。

# 关键属性

| 属性 | 值 |
| --- | --- |
| 打通日期 | 2026-10-29（集群内） |
| 打通验证 | 26 次模型调用 → 18 个标签 |
| 幂等依据 | 2026-11-03 改为「**规范化内容摘要**」（此前为其他方式） |
| 后续迭代 | 11-03~11-06 的幂等 / 回调 / 分维阈值（`[D]` 权威，见 [[三批材料的权威分工]]） |

# 数据流位置

```
商品变更 → MQ → [[MQ 消费链路]] → [[正式打标链路]] → [[异步入库方案]]（tag_product）
```

异步入库（10-30）与 MQ 幂等（11-03）是**同一条写入路径的两面**。
