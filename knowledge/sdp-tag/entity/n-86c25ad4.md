# 定义

商品打标实验台（lab）是打标系统的离线实验环境，承担提示词版本对比、评测执行与输入开关控制。2026-10-19 建立 Spec：`docs/Spec/2026-10-19-商品打标实验台.md`。

# 关键属性

| 属性 | 值 |
| --- | --- |
| label 阈值 | `tag.lab.label-threshold` = **0.7**（见 [[阈值分层]]） |
| 主图输入 | `includeMainImage=true` 固定（10-26），**前端只是隐藏了选项**，并非关闭 |
| 默认判分口径 | `lab-accuracy-v3-inference`（10-27 起，此前为 strict，见 [[判分口径]]） |
| 请求协议 | [[四段结构协议]] `jev_noul_v1`（10-21 起唯一） |

# 案例：香薰 0.640 归因

10-20 对「香薰」得分为 0.640 的排查结论：**真因是「香氛品类」维度门 0.74，不是蜡烛判错**。这是「分维阈值」思路的早期证据（见 [[分维阈值机制]]）。
