> 正式打标默认模型（2026-10-29 起，阈值 0.9，取代 doubao 0.999；曾观测到 503），同时是标签生成模型与三评第一判模型，构成自评偏差。

# qwen3.8-flash

## 定义

`qwen3.8-flash` 自 `1cbcabb`（2026-10-29）起成为正式打标链路的默认大模型，配套阈值 **0.9**，取代历史默认 `doubao` + 0.999。同时，它既是打标阶段的**标签生成模型**，又是 [[三评架构]] 的**第一判（J1）模型**。

## 关键属性

| 项 | 内容 |
| --- | --- |
| 接入时间 | 2026-10-29，提交 `1cbcabb` |
| 默认阈值 | **0.9** |
| 状态 | 正式打标默认 |
| 已知风险 | 曾被观测到 **503**；若生产仍配置此模型且 503 未解决，带主图的跑批**实际会失败** |

- J1 判全部输出对（qwen 组实测 5,707 对）。
- 生成与判定同源 → **自评偏差**；三评是缓解，不是消除。
- 也出现在打标侧 judge 候选（`llm.judge.provider`）中，见 [[判分模型清单]]。
- 与 [[判分模型清单]] 中的 `gpt-6.1-sol`（J2）、`grok-4.7`（J3）协作。
- 偏差影响 [[准确率口径]] 的可信度。

## 与其他模型的对照

同 0.7 阈值下的准确率：doubao 65.2 / qwen 75.7 / JEV 85.6。**但这组差异远小于口径差异**（strict 68.2% ↔ inference 88.0%，19.8 pp），因此模型间比较必须与口径并列陈述，见 [[rubric 判分口径]]、[[评测噪声与可比性]]。

## 已失效结论

- **B14**：「doubao 0.999 是正式打标默认」——`1cbcabb`（2026-10-29）后已切至本模型 + 0.9；doubao 只在**恢复场景**适用。见 [[doubao]]。

## 待确认

- **E3：当前生产用哪个模型？** 若仍是 `qwen3.8-flash` 且 503 未解，带主图的跑批会失败。这是复核任何近期评测结论的前置条件。

## 关系

- [[doubao]] — 被取代的历史默认模型。
- [[jev]] — 同阈值的对照模型（85.6）。
- [[判分模型清单]] — 本模型也出现在打标侧 judge 候选中；J2/J3 协作关系见该清单。
- [[三评架构]] — 本模型担任第一判（J1）。

## 易误解

- 说「judge 准不准」时，若不区分打标侧 judge 与评测侧 judge，会把生成模型的偏差与判定模型的偏差混算。
