# 判分模型清单

## 定义

打标与评测中使用的外部模型集合，各自职责不同，不可互换讨论。

## 关键属性

| 模型 | 归属 | 职责 |
| --- | --- | --- |
| `qwen3.8-flash` | 打标 + 评测 | 标签生成 + 三评第一判（见 [[qwen3.8-flash]]） |
| `gpt-6.1-sol` | 评测 | 三评第二判，**只判第一轮 unknown**，见 [[三评架构]] |
| `grok-4.7` | 评测 | 三评第三判，**只判第二轮翻转** |
| `doubao` / ark | 打标（历史） | 历史方案 label 阈值 **0.999**，见 [[阈值体系]] |
| `jev-1.13.0` | 打标 | 打标侧 judge 判分源，输出 0~1 `noul`，见 [[JEV 百炼决策模型]] |

## 关系

- 打标侧 judge 由 `llm.judge.provider` 选择，与评测侧 judge 完全同名不同物，见 [[judge 三值判定]]。
- `official` 口径下 J1/J2 并发、J3 只判分歧，见 [[评测工具]]。

## 易误解

- 三评并非「三个 judge 全判」；约 12,851 对在第一轮就定性，后续无复查。
