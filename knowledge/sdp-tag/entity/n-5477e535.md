> 与打标解耦的结果外发模块，需显式触发，承担重放、再回调一次与 SUPERSEDED 判定。

# 定义

回调服务负责把打标结果回写给外部租户，与打标链路**解耦**：状态可随时回调，但必须显式触发。

# 关键属性

- **重放语义**：内容相同 → 重放已有结果并**再回调一次**；内容变化 → 删旧投递行 + merge + 重新排队打标；过期结果置 `SUPERSEDED` **不重放**。见 [[重发/重放语义]]。
- **节流**：窗口内（默认 60s）已投递的只确认不重发。
- **投递行整体重建**：`materializeResult` 对 `callback_done` 会直接返回，必须先把事件置 `TAGGED`。
- **配置分层**：URL / header 名放 [[sys_config 配置中心]]，key 真值放 [[Secret]]，见 [[回调配置分层]]。
- **路由**：按载荷 `brand` 选 key，查不到则跳过回写并打 ERROR，见 [[按 brand 路由 key]]。

# 关系

- 消费 [[打标系统]] 的结果，读取 [[TagTaskRunSpec]] 维度的快照语义。
- 依赖 [[sys_config 配置中心]]（Redis hash `<tenantId>:sys_config`）与 [[Secret]]（环境变量）。
- 目标租户示例：[[ZARA 租户]]（tenant 235）。
