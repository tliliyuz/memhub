> 生产环境的打标主链路，2026-11-05 重构（65bda8d）后阶段只剩 scene + label，阈值读 tag.pipeline.label-threshold=0.9。

# 定义

正式打标链路（打标主链路）是生产环境执行商品打标的服务。10-26 建立正式打标 Spec；11-05 重构（提交 `65bda8d`）。

# 关键属性

| 属性 | 值 |
| --- | --- |
| 阶段 | scene + label **两阶段**（见 [[阶段演进]]） |
| label 阈值 | `tag.pipeline.label-threshold` = **0.9**（见 [[阈值分层]]） |
| 历史 doubao 方案 | doubao 0.8 / **0.999**（10-27 确认，见 [[Ark 决策模型（doubao）]]） |
| 请求协议 | [[四段结构协议]] `jev_noul_v1` |
| 分维阈值 | 支持机制、无默认值（11-05，见 [[分维阈值机制]]） |

# 重要约束

`deploy/k8s/api.yaml` 的 env **没有覆盖阈值**——改 yaml 不会改阈值。该部署清单属于 [[TKE 集群]]。

# 数据流

```
商品输入（含主图）→ scene 阶段 → label 阶段 → 直标命中
                                              ↘  ∪ [[标签图谱]] 补全 → 最终标签
最终标签 → [[异步入库方案]]（tag_product）
```

补全路径没有分数、不受阈值约束，见 [[补全路径]]。
