Semantica（v0.7.0）是一个 Python 知识库/知识图谱构建工具，提供数据摄取、解析、语义抽取、知识图谱与向量存储、CLI、MCP server 和 REST API。模块包括 ingest、parse、semantic_extract、kg、vector_store、graph_store、pipeline、change_management 等。
