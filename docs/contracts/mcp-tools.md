# MCP 工具契约

> 版本：0.2（首版只读）
> 适用范围：MCP 工具、授权和传输契约。
> 不负责：部署拓扑、凭据发放和生产验收记录。
> 设计原则：只读、以 Markdown 为真源、先授权与校验再读文件。

## 1. 工具

| 工具 | 参数 | 返回 |
|---|---|---|
| `kb_search` | `query`（最多 512 字符）、`project?`、`kinds?`、`tier?`、`limit?`（默认 8，1–50） | `results` 含 ID、标题、tier、摘要、更新时间、分数和 `matched`。默认只搜 `canonical`，可显式选择 `candidate` 或 `all`。无结果返回空列表和 `hint`。`matched: fts` 为历史兼容值，当前是 Markdown 关键词打分，不是索引或向量召回。 |
| `kb_read` | `id`（完整 `project/kind/slug`） | 节点元数据、正文（最多 8192 字符，截断标记 `truncated`）和可见入边/出边（各最多 20 条）。受限调用不返回原始来源引用、设备信息或元数据中的跨库节点引用。 |
| `kb_related` | `id`、`depth?`（默认 1，1–2）、`predicates?`、`limit?`（默认 30，1–50） | 邻接子图；边单独限制为最多 100 条并标记截断。 |
| `kb_audit_list` | `limit?`（默认 50，1–50）、`offset?`（默认 0） | 只读分页，现算矛盾、断链、孤立、低置信、陈旧等问题；受限调用的结果是授权范围内的视图，不代表全图审计。 |

除上述参数外不接受额外字段，也不做字符串到数字等类型转换。stdio 保留四个既有工具名及文本 JSON 结果，不依赖 Semantica。首版没有创建、修改、归档、恢复或治理写入工具，不兼容旧 Team Brain 工具名。

## 2. 可见范围

- 本地 stdio 以本机进程权限访问活跃库。共享工具层也接受由宿主提供的有限库集合；空集合不得解释成全库权限，调用参数不能改变授权集合。
- 只从合法项目、节点类型和 slug 对应的普通文件读取。跳过链接、重解析点、保留目录及归档库，不递归扫描整个根目录。发现未完成的归档/恢复或写锁正忙时返回可重试错误；不返回中间状态。
- 受限调用仅扫描授权库的节点和边文件。在判断边的端点时只接受完整 ID（不能把全局短别名在子集内重新绑定）；未授权端点或无法安全归属的记录不进入结果、提示或审计。已归档的库也不进入结果。知识正文是资料，不是工具指令。

## 3. 错误

工具错误保留 MCP `isError`，附稳定的业务码。不存在的节点与越权直读均返回 `3001`。显式搜索未授权库返回 `3003`。非法参数返回 `3004`。归档恢复待处理、写锁繁忙或读取超时返回可重试的 `3006`。读取失败返回 `3007`，不返回服务器路径或底层异常文本。受限审计不报告端点无法安全解析的断链，不替代全库审计。

## 4. 传输与鉴权

- 本地 `memhub mcp` 继续走 stdio。HTTP 接入默认关闭；启用后由 kb-api 在精确 `/mcp` 路径提供无状态 Streamable HTTP（JSON 响应，不提供 SSE 监听）。协议协商由官方 MCP Python SDK 处理；不复用 stdio 的 JSON-RPC 解析器。不调用模型，也不对外提供写操作。
- HTTP 每个请求须携带独立的 `Authorization: Bearer` 凭据。配置只保存高熵随机令牌的 SHA-256 摘要、`mcp:read` 作用域、UTC 有效期与非空库名单。凭据过期、缺失或无效返回 401，浏览器 Cookie 或采集 `device_token` 不授予权限（ADR-0003）。吊销删除该摘要并重启服务；无在线发放接口，不改数据库。
- HTTP 只接受不带 `Origin` 的机器客户端访问，入口不转发至 SPA。POST 请求体最多 16 KiB；最多一个 POST 在处理，其余返回 429。禁用、非法路径与鉴权失败均不能触发查询。公网接入、真实客户端联调与生产资源预算单独验收。
