# ADR-0009 采集器按设备授权写入已登记目标

| 属性 | 值 |
|:---|:---|
| 状态 | superseded |
| 被替代于 | [ADR-0010](ADR-0010-collector-target-without-grant-file.md) |
| 日期 | 2026-11-21 |

## 背景

ADR-0003 的设备凭据只限定接口，并没有限定可写知识库。`auto` 和旧队列回退到 `source_id`，使未登记的目录成为知识库。

## 决策

- 保留设备凭据和现有鉴权；采集写入另按设备 ID 和显式项目 ID 精确授权。授权文件由运维配置、无通配符，不包含凭据。注册设备或创建知识库不授予写权限。
- 目录存在不等于登记。采集提交时要求登记且活动，worker 在调用模型前及写入锁内复检；没有旧目标则拒绝，不猜测、不改投。管理台上传保留独立鉴权。
- 拒绝目标使用相同的源级业务错误，不披露已有库；暂不可判定时失败关闭。细节见 [采集契约](../contracts/ingest-api.md)。

## 备选与否决理由

- 设备已注册即允许写所有库：违反最小权限。
- 将库授权编码进设备 token：变更授权需换 token，不能独立撤回。
- 不明确时等待分配或自动推断：不能保证目的地和用户选择一致。

## 后果

部署前须登记目标并配置设备授权，协调 ingest 和 worker 切换。旧内容不回填、不改投；被拒队列记录保留供人工处置。
